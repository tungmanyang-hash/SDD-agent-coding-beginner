## 1. 一句話視覺方向

晚餐選擇器要讓正在廚房、時間有限的下廚者感到**溫暖、清楚、不催促**；以大而直接的任務表單與易於比較的文字結果卡，讓他不用離開頁面就能選定替代食材。

## 2. 視覺關鍵字與界線

| 類別 | 要有 | 不要有 |
| --- | --- | --- |
| 整體氣質 | 溫暖、實用、可信任、安靜 | 花俏、玩具感、企業後台感、焦慮倒數 |
| 資訊密度 | 一個核心任務、寬鬆留白、清楚分組 | 首頁功能牆、密集卡片與多層導覽 |
| 色彩 | 米白背景、白色內容面、琥珀主行動色、深灰文字 | 多個高飽和競爭色、過度食物照片 |
| 文案 | 台灣繁體中文、短句、具體行動語句 | 技術術語、模糊按鈕、過度行銷文案 |
| 動態 | 150–200ms 的 focus、按鈕與 loading 回饋；支援 reduced motion | 自動播放、視差、與任務無關的動畫 |

不可妥協：

1. 首屏立刻看得懂「缺一樣食材，也能繼續做原本的菜」。
2. 結果先給替代食材和用量，再給理由與料理調整。
3. 每個失敗狀態都要讓使用者知道下一步，而不是只顯示錯誤。

## 3. 版面與資訊層級

### 首屏

| 順序 | 元素 | 內容 |
| --- | --- | --- |
| 1 | 品牌文字 | `晚餐選擇器`；無需圖像 logo 或主導覽。 |
| 2 | H1 | `缺一樣食材，也能繼續做原本的菜。` |
| 3 | 說明 | `輸入菜色、缺少的食材和家中現有食材，快速找到可行替代方式。` |
| 4 | 任務表單 | 原菜色（必填）、缺少食材（必填）、家中相關食材（選填）。 |
| 5 | 主行動 | `查看替代建議`；全寬、醒目、在手機首屏可見。 |
| 6 | 輔助文字 | `家中食材可用逗號分隔，例如：雞蛋、洋蔥、番茄醬`。 |

### 版面規則

- 手機：單欄、左右 16px、主按鈕全寬；不使用固定底部按鈕以免遮住表單或鍵盤。
- 平板：單欄、最大寬度 640px，置中。
- 桌面：最大內容寬度 960px；表單在左、結果在右，結果出現前表單置中。
- 結果出現後不離開同一頁，平滑捲至結果標題；使用者可隨時回到表單修改。
- 不可出現水平捲動、隱藏的重要 hover 操作、輪播、側邊欄或多層導覽。

## 4. 視覺參考

此 POC **沒有外部視覺參考檔案**。Claude 應依本文件的 token 與版面規則原創實作，不得模仿特定品牌或複製第三方 UI。

## 5. 視覺 Token

| Token | 值 | 用途 |
| --- | --- | --- |
| `color.background` | `#FFF9F3` | 全頁背景 |
| `color.surface` | `#FFFFFF` | 表單、結果卡 |
| `color.primary` | `#B45309` | 主要 CTA、focus ring |
| `color.primary-hover` | `#92400E` | CTA hover / active |
| `color.text.primary` | `#1F2937` | 標題與正文 |
| `color.text.muted` | `#6B7280` | 輔助說明 |
| `color.border` | `#E5E7EB` | 輸入與卡片邊框 |
| `color.success` | `#166534` | 已選方案確認 |
| `color.error` | `#B91C1C` | 表單與服務錯誤 |
| `font.family` | `system-ui, -apple-system, "Noto Sans TC", sans-serif` | 全站 |
| `font.heading` | desktop 28/36/700；mobile 24/32/700 | H1、區塊標題 |
| `font.body` | 16/24/400 | 正文、表單 |
| `font.caption` | 14/20/400 | 輔助訊息 |
| `space.scale` | 4、8、12、16、24、32px | 全站間距 |
| `radius.md` | 12px | 輸入、按鈕、卡片 |

色彩對比在實作後必須以實際文字／背景組合測試；錯誤與成功不可只靠顏色傳達。

## 6. 元件外觀

| 元件 | 規則 | 必備狀態 |
| --- | --- | --- |
| Button | 高度 48px、圓角 12px、字重 600；每畫面一個 primary CTA。 | default、hover、focus-visible、disabled、loading |
| Input / Textarea | label 在上、16px 正文、12px 內距、1px 邊框；錯誤文案在欄位下。 | default、filled、focus、error、disabled |
| Result card | 先列替代食材與用量，再列做法修改與味道／口感差異；行動置於卡片底部。 | default、selected、unavailable |
| Feedback | 用 inline message；loading 有文字，錯誤包含下一步。 | loading、error、empty、success |

## 7. 必做畫面與狀態

| 畫面／狀態 | 必要內容 | 主要行動 | 完成條件 |
| --- | --- | --- | --- |
| 初始 | 品牌、H1、說明、三欄表單、主 CTA | 查看替代建議 | 對應 FR-01～FR-03 |
| 輸入錯誤 | 原菜色或缺少食材的具體 inline 錯誤 | 修正欄位 | 不提交且 focus 到第一個錯誤 |
| 處理中 | 「正在找可用的替代方式…」與 loading indicator | 等待 | 防止重複提交、保留輸入 |
| 結果 | 2–3 張方案卡；每張含替代物、用量、做法、差異、選擇按鈕 | 選擇這個方案 | 對應 FR-04～FR-08 |
| 已選 | 被選卡的清楚狀態與「可以開始料理了」 | 修改食材 | 對應 FR-08 |
| 無結果 | 找不到合適替代的原因與恢復路徑 | 修改食材／換一道菜 | 對應 NFR-04 |
| 服務錯誤 | 保留輸入、非責備式錯誤訊息 | 再試一次 | 對應 SAD 圖 4 |
